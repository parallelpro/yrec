## Rotation (41 files: rotation/, seculr/, microdiff/, shape/) -- summary

The 2026 conversion is faithful but shallow: names are readable, yet the F77 skeleton is intact everywhere -- `continue`/`if (idx > max)` goto residue, unindented else-blocks 100-300 lines long, blank-line blocks where COMMON declarations used to be, and 15-22-argument lists (secular_transport -> diffuse_composition_driver x2, am_advection_diffusion_coeffs). The biggest clarity costs are (1) dead computation that survives "for comparison" or as leftover scaffolding (viscos Endal-Sofia branch, am_advection residual_check/damping, mid_timestep_model 197-352, banded_solver commented block, evolve_angular_momentum BUR-ST branches hardwired off), (2) the same 4-5 idioms copy-pasted across files (CZ-extent search x4, equal-grid construction in am_transport_grid/composition_grid, RK4/Newton in shape x2-3, microdiff species blocks x3, Lagrangian interpolation x3 in circulation_velocities, LW metal branch), (3) multi-meaning flags and misnomers (`fully_convective_flag` = "skip settling" for three reasons; `no_am_transport_in_core` zeroes all zones; `log_luminosity*` arrays hold linear L/Lsun; `species_fraction` returns a delta; `chi_grid_scale(2/9/11)` when named controls exist), and (4) callers' arrays converted in place to Bahcall-Loeb units (microdiff_setup/gravitational_settling_setup) and restored elsewhere. Numerics-wise, nearly all "does not make sense" items were already caught by sweeps 10/11; the genuinely new ones are dead-code findings and one accepted-on-exhaustion convergence path that reads like a bug but is documented behaviour.

## Structural recommendations

1. Equal-grid toolkit module (`rotation/seculr/equal_grid_lib.f90`): CZ-extent search, zone-mass construction, edge-coefficient interpolation, dchi/dr Jacobian, and the osplin scratch (`rot_scr%xtab/ytab/xval/yval`) as explicit arguments. Replaces the four CZ-search copies and the am_transport_grid/composition_grid duplicate; makes the i1 fix apply everywhere. Cost M; class A (pure extraction, verify byte parity on the standard-solar and rotating examples).
2. Secular-iteration state type: a `type(seculr_iter_state)` (timestep, sub-timestep, iteration, cut_count, flags, region bounds, species range) passed to diffuse_composition_driver, diffuse_composition, check_angular_momentum, check_composition, am_advection_diffusion_coeffs instead of 15-22 positional arguments; also the natural home for the "unconverged accepted" status so secular_transport:505/509 becomes explicit. Cost M-L; class A.
3. Dead-code purge in one commit with a byte-parity check: mid_timestep_model 197-352, evolve_angular_momentum BUR-ST branches, viscos Endal-Sofia arithmetic, am_advection residual_check/coeff_matrix_orig/damping_factor/theta_term, banded_solver 114-152, diffuse_composition dcomp/sum_species, microdiff_mte debug print, zone_moments_of_inertia prev_log_*/spherical_moment_of_inertia, rotation_shape_factors aintt, circulation_velocities commented F77. Roughly 500 lines removed. Cost S-M; class A.
4. Species-descriptor tables: one `species_props` (name, A, Z) in a shared module used by viscos, gravitational_settling_setup, microdiff_coefficients and thoul_diffusion callers; and a per-species diffusion descriptor (composition column, enable flag, eq array, delta array, floor) driving microdiff.f90/microdiff_etm.f90 loops. Removes three-way copy-paste and the bare 1/2/3/4/5..11 indices. Cost M; class A.
5. Microdiff unit hygiene: setup routines produce local `*_bl` copies; callers' arrays stay intent(in); `star%bl_*_scale` set in one place (both setup routines currently define them). Enables making thoul_diffusion's `mass_fraction` intent(in) and removing the restore code in microdiff_etm/equal_to_model. Cost M; class A (byte-safe if the same double-precision products are used in the same order).
