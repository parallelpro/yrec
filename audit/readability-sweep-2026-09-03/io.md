## io/, math/, numerics/, state/ -- summary

The 26 files split cleanly into three groups. (1) The 2026 MESA-style output stack (yrec_output, history_output, profile_output, output_columns, run_log, write_mod_model/read_mod_model, write_output_headers, luout_lib) is well designed: private modules, ierr chains, pure readers of star_info -- essentially clean. (2) The legacy readers/writers and the two grid remappers (read_controls, controls_lib, read_yrec7, read_model2, equal_to_model, model_to_equal, print_allard_tables, write_gyre_pulse) carry the bulk of the debt: hundreds of stale path comments ("core/read_input.f90", "const_lib", "setup/remap.f90" -- none exist), dead DATA/COMMON archaeology, dead debug prints, computed-and-unused blocks, and a read-time side effect on the mixture. (3) numerics_lib.f90 (3249 lines) is a faithful F77 port whose real problem is duplication: five near-identical spline/interpolation routines (cspline/kspline, splinc/splinj, splint/splintd2, interp/intrp2) plus fixed-size `json`/`nmax=100`/`np=100` scratch, single-precision literals, and comments that describe SAVE semantics the code no longer has. The state/ modules (controls_sync_lib generated, phys_const_lib, star_info_lib) are fine apart from a handful of stale path comments and empty placeholder blocks. Three items below look like actual logic errors that are not in ROADMAP 10/11 (equal_to_model NPT=2/3 indexing, tridia's no-op rescale, interpret_kind_cards' Z=0 mixture set at read time); the bsstep underflow guard and equal_to_model X floor/cap are known.

## Structural recommendations

1. **One spline/interpolation family in numerics_lib.** Collapse cspline/kspline, splinc/splinj/splnr, splint/splintd2, interp/intrp2 into four general routines with explicit-shape `(n)` dummies and automatic scratch; delete the zero-caller ones (splinj, splnr). Mechanism: thin wrappers first (byte-identical), then repoint the ~20 call sites (kap/, atm/tables, eos/scv, setup/rezone, rotation/seculr). Enables removing `json` from numerics_lib entirely and closes the "silently static arrays" debt for this module. Cost M. Class A.
2. **Make model_to_equal / equal_to_model one module with a shared stencil helper and an explicit grid type.** Both files hand-roll the same 4-point Lagrange weights three times, mix model-index and equal-grid-index bounds, and rely on a "JVS fix" clamp. Mechanism: `type equal_grid` (n, r, x, ...) plus `interp4(x, y, i0, xt)`; validate `num_equal_points>=4` once at construction and return ierr. Enables fixing the NPT=2/3 indexing without touching numerics (the weights are identical, so byte-safe for n>=4). Cost M. Class A (the FP-exact `mod` test at model_to_equal:63 stays unless deliberately reseeded, B).
3. **Single source of truth for control defaults.** read_controls carries the legacy single-precision literal defaults (1194-1364) while controls_state_def.inc holds the new-style d0 values; they disagree in places. Mechanism: legacy path seeds from `controls_state()` and only overrides what the legacy card semantics require; delete the literal table. Enables shrinking read_controls by ~200 lines and makes gen_controls_state.py the only place defaults live. Cost M. Class B if any regression case runs through legacy defaults (check the matrix), else A.
4. **Finish ierr in the legacy readers and pulse writers.** read_model2 has no ierr; read_yrec7 uses `end=` and no iostat; read_mod_model's first read is unguarded; write_gsm_pulse ignores `herr`; output_columns leaks a unit on error. Mechanism: `iostat=ios` on every read/open, propagate through the existing ierr chain (yrec_output already has one). Enables the driver to report a bad restart file instead of a runtime trace. Cost S-M. Class A (error paths only).
5. **Comment hygiene pass driven by grep, not by hand.** ~100 comments across io/, state/, numerics/ cite files, COMMONs, or SAVE semantics that no longer exist ("core/read_input.f90", "const_lib", "SAVE preserved", "stub stops", "ivers 300"). Mechanism: a one-off script listing every `src/...f90` or `common/...` path mentioned in comments that does not resolve; fix and add the check to gate1 as a warning. Enables trusting headers again, which every later review depends on. Cost S. Class A.
