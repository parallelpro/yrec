## core (driver / Henyey solver / envelope / setup, 27 files) -- summary

The 27 files split into three tiers. (1) The Henyey core (henyey_eliminate, henyey_solve, henyey_coefficients, henyey_iterate, evolve_step, run_yrec) is numerically faithful and already de-tramped, but still carries F77 driver artefacts: a relay chain of solver flags declared intent(out) at the bottom and threaded through SAVEd driver locals, dead counters (kenv/katm) threaded through six files, sign-encoded flags (dt, fcorr0), and 40-140-line stale "cross-callee naming" headers that describe code that no longer exists. (2) The envelope/atmosphere stack (envint_lib, envint_kernel, envelope_derivs, atmosphere_derivs, surfbc, stitched_model, rebuild_envelope, read_starting_model) is where the real debt is: the envelope refit is written out twice almost verbatim (read_starting_model 813-1034 vs rebuild_envelope 113-323), configuration is passed to atm_get by save/override/restore of star%job step sizes at three sites, the "star-blind" kernel's integrands read star% and set star%iovim, and the 22-arg atm_get signature is called with 4 dummy arrays at every site. (3) The new 2026 modules (observables_lib, monte_carlo, stop_conditions, yrec_capi, yrec_reset, star_setup, neutrino_flux_table, point_scratch_lib) are clean and need only small trims. One genuine modernization regression was found (read_starting_model.f90:829, linear Lsun used where log10 Lsun is needed, introduced in 6e31b68) plus one latent new-code bug (envint_kernel one-way luminosity swap). Everything else flagged is inherited or cosmetic.

## Structural recommendations

1. One envelope-refit implementation (rebuild_envelope called from read_starting_model, log_unit argument). Cost M. A if print units preserved.
2. atm_get configurable via optional envint_config; optional vertex outputs; remove three save/override/restore blocks and the dummy arrays (read_starting_model returns at 870-873 without restoring the step sizes). Cost M. A.
3. henyey flag relay -> locals/parameters of henyey_coefficients; delete kenv/katm across surfbc -> atm_get -> kernel -> bsstep -> derivs. Cost M. A.
4. Single profile-column registry: stitched_model profile_value select-case (329-401) and compute_seismic_columns (246-254) duplicate io/yrec_output column semantics. Cost M. A.
5. Single-source geometry helpers (log10_radius_from_L_Teff, spot_adjusted_log_teff, shell_masses_from_log_mass, array-section reversal), keeping each caller's operand order. Cost S each. A.
