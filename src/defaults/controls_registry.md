# The controls registry

GENERATED by tools/gen_inlist.py -- do not edit. A control's description
and default are its declaration in `io/controls_buffer.f90` (the comment
above it, its initializer); its names, group, home, run copy and use are
its row in `defaults/controls_registry.tsv`. Edit those, then regenerate.
Every control: its name in a single-file
inlist, in the legacy CONTROL/PHYSICS decks and in the code
(controls_buffer, star%control or star%physics), its default and what it does.

- **home**: `control` or `physics`, the group: the star holds the control
  in the record of its namelist group, star%control or star%physics, never
  changed after the controls read; `buffer` is the read's buffer only (an
  input-only or unused control). `tools/check_boundaries.py` checks it.
- **run copy**: for a control the run changes (the run cards the
  calibrations rewrite, the stops they disarm, the latches, the working
  values), the star member the run keeps as its working copy, set from
  the control by the controls read (star_info_lib documents it); the
  control keeps the deck's value.
- **settings**: the settings fields a domain's builder in `setup/` sets
  from the control (`<record>%<field>`); blank when no builder statement
  names it (core reads it, or a builder derives from it through a local).
  `tools/check_boundaries.py` checks it.
- **used**: `run`, read after the controls read; `read`, only during the
  read (an input-only control: `map_user_inputs` or `derive_controls`
  turns it into others); `none`, nowhere. `tools/check_boundaries.py`
  checks it.
- **status**: `live`, read by the inlist format (an inlist name in
  parentheses is an older one it still accepts) and, unless its legacy
  name is `-`, by the legacy decks; `legacy`, read from the legacy decks
  only; `unused`, read from the legacy decks only and used nowhere;
  `derived`, a member no deck sets. The columns are described in
  `tools/controls_registry.py`.
