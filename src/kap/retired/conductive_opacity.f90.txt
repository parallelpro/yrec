! Formulas the F77 CONDOPACPINT (LLP, 5/31/04) kept as
! comments in its conductive-opacity mixture, taken out of
! kap/conductive/conductive_opacity.f90 (compute_conductive_opacity) in
! 2026 so that the live code holds no commented-out statements. They are
! an earlier mixing rule, by mass with X, Y and Z, which the code replaced
! by the ionization-weighted harmonic mean of the species' conductivities
! it uses now. To revive one, translate it to the current names (condx,
! condy, condz are cond_h1, cond_he4, cond_ox; qodc, qotc the mixture's
! derivatives) inside compute_conductive_opacity's main branch, and
! measure the change (it moves every deck's conductive opacity).
!
! The no-conduction start value (now no_conduction_log10_opacity):
!       OC = 1D50
!       OCL = LOG10(OC)
!
! The mixture's log conductivity, main branch (log rho >= -6) and the
! low-density branch:
!           CONDL = LOG10( (X + 1D0) / 2D0 ) -
!     *             LOG10( X*condx + .5d0*Y*condy + .5d0*z*condz)
!
! Its derivatives:
!           QODC = 2D0 * CONDL / ( 1D0 + X ) *
!     *          (X*condx*qodcx +.5d0*Y*condy*qodcy +.5d0*Z*cobdz*qodcz)
!           QOTC = 2D0 * CONDL / ( 1D0 + X ) *
!     *          (X*condx*qotcx +.5d0*Y*condy*qotcy +.5d0*Z*condz*qotcz)
!
